# Libra 📚

**Libra** is a smart library management system that combines book circulation with personalized recommendations for students.
(OOPS and RDBMS Proj)

### Tech Stack

* **Frontend:** React, Tailwind CSS
* **Backend:** Java, Spring Boot
* **Database:** PostgreSQL
* **ML:** Python, Scikit-learn

### Features

* Book search & availability
* Issue, return & reservations
* Due-date & fine tracking
* Student reviews & interests
* Personalized recommendations
* Librarian dashboard

### Run Locally

**1. Clone the repository**

```bash
git clone <repository-url>
cd Libra
```

**2. Backend**

```bash
cd backend
./mvnw spring-boot:run
```

**3. Frontend**

```bash
cd frontend
npm install
npm run dev
```

**4. Database**

Create a PostgreSQL database and configure the connection details in the backend environment/configuration file.

**5. ML**

```bash
cd ml
pip install -r requirements.txt
```
