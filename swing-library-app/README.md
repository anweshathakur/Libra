# Swing Library App (Graded Project)

A Java Swing frontend for the Library Management System coursework — login screen plus a book inventory CRUD table.

## Run
```
cd swing-library-app/src
javac *.java
java LoginFrame
```

## Test logins
- Student: `STU-2291`
- Librarian: `LIB-001`

## Files
- `LoginFrame.java` — login screen (student/librarian), has `main`
- `BookCrudFrame.java` — book inventory table (Add/Edit/Delete)
- `Book.java` — model class

This is a standalone course deliverable, separate from the `frontend/`, `backend/`, and `ml/` folders of the main Libra project.
